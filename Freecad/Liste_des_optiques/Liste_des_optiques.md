# Optiques nécessaires pour le freecad : 

## Type de chemin :

### Excitation arrière :

- Collimateur fibre arrière excitation : [F280APC-980](https://www.thorlabs.com/item/F280APC-980)

### Excitation avant :

- Collimateur fibre avant excitation : [F280APC-980](https://www.thorlabs.com/item/F280APC-980)

- Dichroic beam splitter :  [DMLP1180](https://www.thorlabs.com/item/DMLP1180)

- Piezo qui sert de steering mirror : [S-330.8SH](https://www.pifrance.fr/fr/products/nanopositioning-piezo-flexure-stages/piezo-flexure-tilting-mirrors/s-330-fast-piezo-tiptilt-platform-300700)
- Miroir de scan sur le piezo : [PF05-03-P01](https://www.thorlabs.com/item/PF05-03-P01)

- Miroir au milieu du 4f : [PF10-03-P01](https://www.thorlabs.com/item/PF10-03-P01)

- lentille de l'objectif : [C330TMD-C](https://www.thorlabs.com/item/C330TMD-C)

### Collection avant :

- Collimateur fibre collection avant : [F280APC-C](https://www.thorlabs.com/item/F280APC-C)

### Config cavité :

- Trouver un bout de fibre
- Trouver un [Piezotube](https://www.pi-usa.us/fileadmin/user_upload/physik_instrumente/files/datasheets/PT230-Datasheet_en.pdf) dans ce style
- Trouver un clamp random à modéliser
