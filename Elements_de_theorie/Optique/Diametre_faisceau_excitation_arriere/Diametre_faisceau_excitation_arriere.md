# Calcul du diamètre du faisceau en sortie de collimateur pour l'excitation arrière

- Dans la fibre, le waist $w_0$ du mode vaut MFD/2 : 
    - $w_0 = 4,6 \mu m$ 

La fibre étant dans le plan de Fourier (objet) de la lentille du collimateur, le waist du mode en sortie de lentille est donné par :
    - $w = \frac{f \lambda}{\pi w_0}$

- Etant donné :
    - f = 4,59 mm
    - $\lambda$ = 1310 nm

- On obtient bien, pour le diamètre du faisceau après le collimateur :
    - D = 2w = 0,83 mm 

Ca correspond bien à la valeur donnée par Thorlabs.
